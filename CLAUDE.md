# Instrucciones para Claude

## Forma de trabajar
- Ante cada pedido, primero proponer un plan de acción corto (pasos numerados).
- No implementar nada hasta que el usuario apruebe el plan.
- Avanzar paso a paso: completar un paso, confirmar, y recién seguir con el siguiente.
- Respuestas cortas, simples y claras. Evitar textos largos.
- Responder en español.
